STUDENT MANAGEMENT SYSTEM
==========================

Technology:
- HTML
- CSS
- JavaScript
- Browser LocalStorage

How to run:
1. Extract the ZIP file.
2. Open index.html in any modern web browser.
3. Add student details using the form.
4. Records are saved automatically in browser LocalStorage.
5. Use the search box to find students.
6. Use Delete to remove a record.

Project features:
- Add student records
- Automatic grade calculation
- Search/filter students
- Delete records
- Responsive design
- LocalStorage data persistence

No external libraries or server are required.
